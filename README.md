# Room Monitor Python

A Python simulation of an IoT room monitoring system that tracks 
temperature across multiple rooms, detects alerts, and generates reports.

## What this does
- Simulates multiple room sensors with random temperature readings
- Detects WARNING and CRITICAL alert conditions
- Identifies the hottest room across all sensors
- Generates a complete report and saves it to a file

## Concepts used
- Object-oriented programming (two classes)
- Random data simulation
- List comprehensions
- File I/O

## How to run
python room_monitor.py
